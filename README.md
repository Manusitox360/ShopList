# ShopList 📋🧺

**Sistema de Gestión de Lista de la Compra**  
*Gestiona tu lista de la compra con eficiencia*

---

## Características Principales 🚀

- **Gestión de Lista**: 
  - CRUD de aviones y vuelos (solo Admin).
  - Detecta automaticamente si quieres añadir un producto existente.
